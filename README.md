# DevOps Engineer Business Card & Sandbox

A personal DevOps business card web page built with HTML/CSS and continuous integration/deployment  pipelines.

## Project Overview
This repository serves as a showcase for a DevOps engineer's profile while practicing infrastructure automation, GitHub Actions workflows, and static site hosting.

## Features
* **Interactive Web Page**: HTML5/CSS3 landing page styled with custom fonts (JetBrains Mono, Syne).
* **Automated CI/CD**: Automated deployment pipeline configured via GitHub Actions (`.github/workflows`).
* **Container & Web Hosting Ready**: Lightweight static frontend ready for Nginx/Apache or Docker containerization.

## Tech Stack
* **Frontend**: HTML5, CSS3
* **Automation**: GitHub Actions
